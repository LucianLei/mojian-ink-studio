# 墨间 · 书法字帖工坊

完整的 React + TypeScript + Vite 浏览器应用。字体解析、随机分配、逐字编辑、排版和 PNG 导出均在本机浏览器完成，无后端、无外部图片、无字体下载服务。

## 安装与启动

需要 Node.js 22.12+（推荐 Node.js 24 或更新版本）、npm，以及现代浏览器。首次安装需要联网获取开发依赖。

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。默认字体自动加载，无需上传即可生成。Vite 默认仅监听本机。

```bash
npm run build
npx vite preview --host 127.0.0.1
```

构建结果位于 `dist/`。可以使用任何静态文件服务器部署该目录；不要直接双击 HTML 文件。默认字体使用 Vite BASE_URL，部署到子目录时执行 `npm run build -- --base=/子目录/`。

失败字体保留在管理列表，展示原因，不能启用，不进入随机池。不同浏览器的字体校验结果可能不同。TTC 在本机内存中提取集合的第一个字体后交给 FontFace；不选择集合内其他字体。不会为让字体强行通过而删除字体表或改变字形。

默认文件会随项目和构建产物分发；它们的授权由提供者管理，项目没有替这些字体授予新的许可。

## 使用

1. 等待默认字体加载，或多选上传、拖入 TTF、OTF、TTC。
2. 输入文字后，停止输入约 350 毫秒即自动生成；中文输入法选字期间不会生成。默认字体加载完成后，也会自动显示初始示例。关闭“自动生成”后仍可用顶部按钮手动生成。自动更新通过字素簇匹配保留未改动字符的 ID、字体、精修和随机走势。
3. 大小错落默认 ±22%，可调至 ±45%。改变幅度会沿用原随机数，保留手动大小比例、字体及偏移；幅度和开关也可撤销。字体、偏移与旋转开关用于后续生成/整体随机。
4. 在右栏调整书写方向、画布和排版。新增“自由章法”：规整、自然（65%）、奔放（100%）预设及 0–100% 错落强度。字距、列距、起笔、横向摆动、行列走势和倾角会协调变化；强度调节不重新随机，且保留相对于槽位的手动偏移。强度较高时允许书法式交叠，可调大间距或降低强度。
5. 点击画布单字或字符列表，调整字体与参数；拖动微调。方向键移动 1 逻辑像素，Shift + 方向键移动 10 像素。输入框中的方向键保持正常行为。
6. 撤销、重做支持单字参数、一次完整拖动、整体随机、生成、排版；快捷键为 Ctrl / ⌘ Z、Shift Ctrl / ⌘ Z、Ctrl / ⌘ Y。历史保留最近 80 次操作。
7. 生成前同时检查 cmap 覆盖和离屏 Canvas 的实际可见像素；声明有字但绘制为空、渲染异常的字体不会成为该字符的候选。当前字符无法显示或字体被删除时，按字体管理顺序尝试下一款启用且可绘制的字体，并将替换写回作品状态，保留 ID、随机走势、字号、缩放、加粗、旋转及偏移。全部失败时用红框和 Unicode 编码标记，不以系统字体悄悄补字。裁切或超出画布会提示。字体停用仅影响后续随机候选；已分配的字仍使用原字体。删除字体后，引用它的字符自动切换到其他可显示字体；没有候选时才标记缺字。
8. 选择纯色、细纹宣纸、透明背景和田字格 / 米字格。默认 PNG 不含辅助线，勾选后才包含。
9. 选择 1× / 2× / 4× 或自定义像素，点击顶部导出直接下载。单边最大 16384 px，总像素最大 3200 万。自定义宽高比例与画布不一致时会拉伸；如需保持比例，输入同比例尺寸。

左栏“生成时删除换行”仅过滤生成内容，保留输入原文；“删除标点符号”按钮按 Unicode 标点类别删除输入中的中英文标点，保留文字、空格及换行。未移除的换行仍表示另起行/列。

默认启用“视觉协调”：加载后用字体实际字形边界和墨色密度估计缩放及细笔画补强，强度 0–100% 可调；单字面板还有额外加粗滑块。补强使用同色字形轮廓描边，不用模糊，不侵蚀粗字体，预览和导出复用同一绘制逻辑。它减少字体间视觉差异，但不会抹平原字体笔意。

预览缩放、窗口尺寸变化、选中字和图片导出不重新随机。全局字号按生成时基准同比缩放单字字号；单字面板的字号为生成时坐标系中的值。所有单字缩放、字体、旋转和槽位偏移都会保留。恢复单字默认参数会恢复该次生成时的参数。

生成时默认播放逐字字体动画：当前字在能实际显示该字的字体间切换，最终定格为作品已保存的字体，再生成下一个字。自动输入只对新增字符播放；整体重新随机会重播全部字符。左栏可关闭动画、调整每字 80–600 毫秒，进度条可跳过。动画期间暂停导出，定格后导出已保存的最终作品；动画不会改变精修参数。系统开启减少动态效果时默认关闭动画。

## 实现结构

- `src/generation-animation.ts`、`src/use-generation-animation.ts`：纯展示层逐字轮转、顺序定格与增量播放。
- `src/glyph-probe.ts`：按字体/字素簇缓存实际像素检测，识别空字形及渲染异常。
- `src/font-fallback.ts`：失败字体顺序回绕替换，结果保存到状态，不重新随机其他参数。
- `src/appearance.ts`：字体字形尺度和墨色密度采样、有限缩放与细字轮廓补强估算。
- `src/fonts.ts`：FontFace 加载、TTC 第一字体提取、cmap 4 / 12 / 13 覆盖检测。
- `src/model.ts`：Unicode 字素簇、稳定 ID、单字编辑状态、随机、逻辑槽位排版、历史。
- `src/render.ts`：实际字形边界对齐、纸纹与辅助线、共享预览/导出绘制、旋转命中、裁切检测、独立高分辨率 PNG。
- `src/App.tsx`：中文三栏界面、字体管理、指针坐标换算、拖动事务、快捷键与参数控件。
- `src/style.css`：桌面与窄屏布局。
- `src/model.test.ts`、`src/changes.test.ts`、`src/fonts.test.ts`、`src/font-fallback.test.ts`、`src/generation-animation.test.ts`：31 项核心逻辑、视觉控制、字体解析和文本匹配测试。
- `tests/app.spec.ts`、`tests/changes.spec.ts`、`tests/font-fallback.spec.ts`、`tests/animation.spec.ts`：四个 Chrome 浏览器端到端测试，覆盖真实字体、自动生成、输入法、过滤、自由章法和导出一致性。

## 已知边界

- 实际字形检测判断是否绘制出可见像素，不能识别字体中的错误字形、异体字或非空占位图形的语义。无候选时保留缺字标记。

- 字形覆盖以 Unicode cmap 检查，不是完整 OpenType 排字引擎。支持字素簇不拆分；复杂文字塑形、cmap14 的特殊异体选择和全部竖排 OpenType 替换不在本项目范围内。
- 竖排标点优先使用字体覆盖的 Unicode 竖排形式；没有该形式时使用原标点。普通点类标点按书写方向放入合适位置。拉丁字符按单字直立绘制。
- 对变化区域不超过 100 万个比较单元的输入，使用最长公共子序列匹配保留旧字符；更大变化仅保留相同前后缀，避免大段输入占用过多内存。
- 全部数据存于当前页面内存；刷新会恢复默认字体并清空作品与编辑历史。没有作品保存/恢复功能。
- 浏览器 Canvas 字体渲染受操作系统与浏览器影响，未加载或校验失败的字体无法使用。不能把真正缺失的字形生成为书法字。
- 默认字体总量较大，首次加载耗时取决于本地磁盘或静态服务器速度。超大画布、导出和很长的文字也会增加内存及绘制开销。
